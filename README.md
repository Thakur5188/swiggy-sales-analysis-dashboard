# 🍔 Swiggy Sales & Business Performance Analysis

## 📊 Project Overview

This project analyzes Swiggy food delivery data to understand sales performance, customer ratings, restaurant performance, food categories, and regional trends.

The goal of this project is to transform raw business data into meaningful insights using Microsoft Excel and an interactive dashboard.

This project demonstrates practical Data Analyst skills such as data cleaning, data analysis, KPI creation, Pivot Tables, and data visualization.

---

## 🎯 Business Objective

The main objective of this analysis is to answer important business questions:

- What is the overall sales performance?
- What is the average order value?
- Which food categories perform well?
- Which restaurants and locations contribute to sales?
- How do customer ratings vary?
- What trends can be identified from the available data?
- Where can the business improve its performance?
